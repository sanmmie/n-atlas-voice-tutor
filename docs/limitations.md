# Limitations

Written to be useful to a judge rather than flattering. Every claim here is either
published by NCAIR/Awarri in the N-ATLaS model card and terms, or measured by this
project and recorded in `validation/`.

## Model limitations (published by NCAIR / Awarri)

| Limitation | Source | Effect in this app |
| --- | --- | --- |
| **Yorùbá quality is low.** Human evaluation: 2.69/5.0 overall, fluency 2.71/5.0, relevance 2.89/5.0, bias/fairness 2.23/5.0 | N-ATLaS model card | Yorùbá mode is labelled "weak" in the UI. Expect broken transcripts, English drift, and stilted replies. |
| **Context length 8,092 tokens** | N-ATLaS model card | `trimToContext()` caps prompts at ~18k characters; the client persists only the last 12 turns. |
| **Bias concerns**; Hausa bias/fairness scores 1.11/5.0 | N-ATLaS model card | Replies may carry stereotypes despite the topic guard. The guard screens topics, not bias. |
| **Dialect and accent bias** | N-ATLaS terms of use | ASR accuracy varies by speaker and region; Igbo in particular varies between standard and regional usage. |
| **Reduced accuracy on children's speech** | N-ATLaS terms of use | The tutor is not currently usable as a primary tool for young children. |
| **Limited code-switching** | N-ATLaS terms of use | Nigerian learners mix languages constantly. Mid-sentence code-switching will be transcribed badly. |
| **Degraded in noisy environments** | N-ATLaS terms of use | Market and street testing will be visibly worse than quiet-room testing. |
| **No hosted inference provider** | Hugging Face model page | The demo needs a self-hosted GPU or a Hugging Face Inference Endpoint. This is a deployment cost. |
| **1000 active end-user cap**, research licence | N-ATLaS terms of use | Fine for a NAIC pilot; commercial scale would need separate licensing. |
| **Gated repository** | Hugging Face | Requires an HF account that accepted the licence conditions. |

## Application limitations (measured by this project)

| Limitation | Detail |
| --- | --- |
| **No measured ASR accuracy yet** | `validation/asr-accuracy.md` is generated by `scripts/evaluate-asr.py`. Until real clips are collected and run, this project has **no** WER/CER figures of its own — only the model card's qualitative statements. |
| **No 50-interaction validation yet** | `validation/README.md` tracks the count. Fabricating interactions would disqualify the submission, so nothing is pre-filled. |
| **Deterministic difficulty adaptation** | Levels come from length/repeat heuristics, not from understanding the learner. A short but correct answer is treated as an error signal. |
| **"Mistake signals" are a proxy** | The count of short or repeated replies is not a count of grammatical errors. N-ATLaS is stateless, so the model cannot know. |
| **Bounded context loses early turns** | A long lesson silently forgets its opening. There is no summarisation. |
| **No TTS model** | See `docs/tts.md`. Yorùbá in particular frequently falls back to a non-native browser voice. |
| **No speaker diarisation** | One voice per utterance; the tutor cannot tell two people apart. |
| **No offline mode** | Every turn needs a network round-trip. On a poor connection the learner waits; the app shows a "thinking" state but cannot queue or retry automatically. |
| **Accuracy figures are per-language averages** | Overall quality is dominated by the better languages. Per-language results are always reported separately. |

## Ethical limitations

- **Voice recordings in the phrase library** must only feature volunteers who
  consented to their voice being published in an open-source repository.
- **Interaction logs contain full transcripts.** Learner identifiers are anonymous,
  but the words a person says are not. `validation/README.md` describes the removal
  procedure for anyone who asks.
- **Topic screening is keyword-based**, not semantic. It catches explicit
  solicitation of sensitive topics; it does not catch subtle bias in the model's
  own phrasing, which is a known N-ATLaS weakness (Hausa bias/fairness 1.11/5.0).

## What we would do next

1. Collect 30+ ASR clips per language across six zones and publish real WER/CER.
2. Expand the phrase library so the greeting, refusal and all prompts are natively
   recorded in every language.
3. Add a lightweight intent classifier for code-switched input, routing Nigerian
   English turns to `NCAIR1/NigerianAccentedEnglish` before the language-specific
   checkpoint.
4. Replace the difficulty heuristic with a small server-side learner profile once
   enough sessions exist to fit one honestly.
